DockForWin 1.0.0

适用于 64 位 Windows。主要验证环境为 Windows 11；Windows 10 的完整兼容性尚未验证。
安装包自带 .NET 10 桌面运行环境，无需另装 .NET。

默认安装到当前用户的 %LOCALAPPDATA%\Programs\DockForWin，不需要管理员权限。升级时沿用已有安装目录。
首次启动不导入开发目录，也不附带任何作者配置、固定应用、桌面小组件、账户或播放记录。
默认固定项为文件资源管理器、可用时的记事本、下载和回收站，均在使用者电脑上动态解析。

设置与日志位于 %LOCALAPPDATA%\DockForWindows。已有设置会保留；卸载保留用户配置。
左键点击托盘图标打开设置，右键可退出。控制中心默认快捷键：Ctrl+Win+A。
时钟读取 Windows 系统时间；普通时钟默认本机时区，世界/城市时钟按所选时区显示。
系统闹钟没有通用的读取接口，闹钟组件提供 Windows 时钟入口，不伪造闹钟时间。
更多使用与构建说明：https://github.com/JoenLee/DockForWin/tree/codex/release-v1.0.0
