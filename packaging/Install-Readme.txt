DockForWin 0.6.0

适用于 Windows 10 2004 及以上的 64 位 Windows。已包含 .NET 桌面运行环境，无需另装运行时。

安装默认位置：D:\DockForWin\App；没有 D 盘时使用当前用户程序目录。默认不创建桌面图标，可以从开始菜单打开程序坞或设置。

首次启动且用户配置不存在时，自动导入 D:\DockForWindows\data 中的现有设置与固定项目，并复制程序坞管理的快捷方式。已有用户配置不会被覆盖。

安装版的配置与日志：%LOCALAPPDATA%\DockForWindows
卸载会移除安装文件与快捷方式，保留用户配置、原工程和原应用文件。

右键程序坞或托盘图标进入设置。再次启动会唤出已有实例。

本安装包未附带任何个人配置、桌面文件或账户资料。首次启动的配置导入仅在本机进行。
