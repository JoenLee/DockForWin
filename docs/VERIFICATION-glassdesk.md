# GlassDesk 透镜算法接入记录 · 2026-11-07

已将 GlassDesk 默认紧凑透镜的 GPU 折射算法接入现有 DockForWindows，未生成或更新 EXE/安装包。

## 范围

生产文件仅改动 `src/DockForWindows/Shaders/LiquidGlass.hlsl` 及其编译资源 `LiquidGlass.ps`。C# 宿主、窗口采样、设置、布局、图标、拖入、换位、倒影、弹跳、全屏退下等生产代码的 SHA256 均未变。

来源为 `iishen717/GlassDesk` 提交 `737b8dc1737e029b292c4348f7d2254b290da971` 的 `TransitionGlass.hlsl` / `AndroidLiquidGlassRenderer.cs`。引入紧凑透镜轮廓、扩展圆角法线及轻微色散；默认扭曲度 .65 对应上游 24 DIP 边缘带和 32 DIP 最大位移。现有折射强度控制位移，扭曲度控制肩部范围及位移；不会改动灯光。保留现有连续三次超椭圆到胶囊的可见轮廓。

现有高光分支逐字核对一致，包括上下高光、左右暗边、下沿白色反光和淡黑底色。外部悬浮阴影代码未改。高斯模糊仍在折射之后，0～24 DIP 连续可调，不导入上游会关掉透镜的纯磨砂模式，也没有导入其固定壁纸材质模式。

仅新增针对性光学测试 `tests/DockForWindows.Tests/GlassDeskOpticsChecks.cs`，并在测试入口增加 `--verify-glassdesk-optics`。许可证/来源位于 `docs/third-party/glassdesk/`。

## 备份

## 已完成验证

- 着色器编译及开发版本构建通过，现有核心检查 **51 通过、0 失败**。测试工程原有两条 nullable 警告仍存在。
- 新增 GPU 实屏检查通过：距上边缘 4、8、16、28 DIP 的绿色通道取样与上游闭式透镜公式相符；例如实测深度 4.68 DIP 时预期绿色 80.14、实测 80。确认改变的是背景位置而非高光亮度。
- 实屏确认中央一比一、上下边缘相反方向、折射强度连续、扭曲度零端点关闭位移、完全透明时去掉底板。保存了 0%、85%、100% 圆润度的渲染图。
- 原有隔离 GUI 检查通过：实际后方窗口进入玻璃，窗口换色和拖动实时更新；采样约 **39.9 次/秒**，仅代表当前机器及本测试场景。Rendering 回调次数不作为显示帧率。
- 高斯磨砂从清透到纯磨砂连续变化，不修改折射与扭曲参数；实屏棋盘细节方差由 6080.7 降到 0.2，背景比例未变，图标不参与模糊。
- 70 个项目自动缩小且全部留在工作区，图标与底板居中；减少项目恢复尺寸。设置深色模式、全屏退下及恢复置顶、反复切换均通过。
- 隔离鼠标悬停检查通过：图标宽度 77→111 物理像素，主图标上浮 54 像素、邻居上浮 29 像素；底板上下位移 0，宽度 705→769→705，左右留白约 14.34 DIP。
- 对修改前已有 47 个源码/构建/测试文件核对：44 个不变，变化仅 HLSL、PS 和测试入口。原 HLSL 几何计算及 LightingOnly 分支逐字一致。运行用户设置未被隔离测试改写。
