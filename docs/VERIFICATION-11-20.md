本轮更新原有 `D:\DockForWindows` 工程，未生成或更新 EXE、安装包。第 21 项只记录为后续设想，未修改首次安装的默认项目或配置迁移方案。

## 实现对应

| 项目 | 当前实现 |
| --- | --- |
| 11 图标外框 | 不规则资源按透明像素边界识别，裁去多余透明留白，等比放入统一 256×256 三次超椭圆容器；已有规则方形图标保留其内容。外框随 Windows 应用深浅模式使用白/黑底，纯白图形按保留 alpha 的反色转为黑形白底。外框上下有固定高光，无调节项。回收站原始图像不处理。倒影复用规范化后的图标。 |
| 12 三栏设置 | 左侧六个目录，中间按模块调整，右侧固定壁纸材质预览。玻璃、边框、阴影、倒影、动画和最近应用数量各自有生效条件；禁用时变灰，原值保留。 |
| 13 左右侧停靠 | 按实际图标显示范围更新侧边底板，统一两侧留白和横向中心；沿屏幕中线居中，容量不足整体缩小。 |
| 14 控件与模糊 | 模块间隔及底下注释分开排版，滑块拇指缩小为 34×22 DIP。模块、预览、按钮及开关采用固定三次超椭圆。设置面板单独采样真实后景、缩小背景纹理后加 24 DIP Gaussian 模糊；文字与控件不参与模糊。 |
| 15 倒影限制 | 所有主题只有完全无底板时才创建倒影。半透明不可用；从玻璃切到完全透明、恢复底板时立即创建/移除倒影，不覆盖原偏好。 |
| 16 模块说明 | 各模块下方注明作用、生效条件、互斥关系、预览/保存区别。 |
| 17 连续目录组 | 左侧目录共用一个连续圆角容器，行间细分隔线，取消条目间空隙。 |
| 18 指定壁纸 | 用户提供的 `ipados-27-brown-rose-abstract-light.png` 作为工程 Resource 嵌入，预览真实从该壁纸取样，外层连续圆角裁剪。 |
| 19 桌面隐藏 | `HideOnDesktop` 与原来的普通窗口自动隐藏分开，默认 false（桌面固定）；前台回到桌面会按该选项处理，全屏判断保持独立。 |
| 20 开机自启 | 系统与启动页面提供开关，保存时修改当前用户的 DockForWindows 启动项；预览与取消不写入。开发版和独立 EXE 分别生成正确的启动命令，携带明确配置目录以继续原布局。保存失败尝试回滚启动项。 |
