# DockForWindows 0.6 本轮验证

2026-11-06，本机 Windows 桌面实测。工程 `D:\DockForWindows`，仍未生成成品 exe。

- `tests/latest-core-results.txt`：48 通过、0 失败，包括删除原快捷方式后的实际启动、图标恢复、配置持久化、折射与高光解耦、全透明、分区和排序。
- `tests/glass-layout-results.txt`：实际屏幕像素确认玻璃显示后方应用窗口，窗口换色实时进入材质；背景像素一比一对齐。
- 高斯磨砂 0%、50%、100% 连续变化，最大半径 24 DIP，参数变化不修改折射和扭曲。真实屏幕棋盘细节方差由 6524.7 降到 0.2；图标不参与背景滤镜。
- 移动测试窗口经过程序坞：背景取样约 39.5 次/秒，观测点经历两次应用/壁纸交替，证明位置随窗口移动更新。该数值为当前测试场景，不代表所有窗口或显示器刷新率。Rendering 回调另有记录，不等同于屏幕呈现帧率。
- 70 个应用与回收站全部位于工作区内，整体自动缩小，图标及底板同时居中；减少项目后恢复，不改用户设定的图标大小。
- 设置窗口即时切换深色，液态玻璃底板独立保留。
- 当前完整测试通过最大化退下、普通窗口恢复置顶与反复切换；部分此前运行因用户切换前台窗口明确标记 SKIP，不计为通过。
- 滑块为两端半圆、中央平直的胶囊。
- 外层投影从内容裁剪中分离，左右暗边增加轻微白色下沿反光。

核心测试只使用隔离配置；当前用户项目与顺序保留。实际桌面固定项曾核对到全部真实图标，后续用户仍可增删，不把旧数量视为实时数量。

Windows 10、真实多屏及混合 DPI、受保护窗口仍需专项验收。界面绘制为 Windows 上的自定义材质，不宣称与苹果系统实现完全一致。
