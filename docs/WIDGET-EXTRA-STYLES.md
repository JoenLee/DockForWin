# 小组件扩展款式与玻璃调节（历史记录）

> 历史实现记录：本文保留早期扩展款式与验证背景。1.0.0 已按作者选择移除其中 18 款旧组件，当前可用模板以 `Models/WidgetOptions.cs` 与 `Models/FigmaWidgetCatalog.cs` 为准；安装与使用请阅读 README.md 和 docs/USAGE.md。


## 玻璃更通透

在“小组件”中选择“液态玻璃”，再展开当前卡片的外观设置：

- **玻璃磨砂**：0% 为清晰玻璃，100% 为最强磨砂。每个模板独立保存，默认 3%。
- **玻璃衬色**：控制表面颜色覆盖，默认约 3.5%；设为 0 可去掉衬色。
- 已放到桌面的组件可以右键“组件设置…”独立修改以上数值。

设置随现有草稿和“保存设置”流程提交。不会修改 Dock 或控制中心的玻璃参数。悬停不放大，手动缩放继续保留。

## 新增 24 个模板

| 分类 | 款式 |
| --- | --- |
| 时钟 | 点阵方形、点阵横向、轨道表盘 |
| 天气 | 点阵实况、圆角温度面板 |
| 日历 | 点阵日期、极简月历、年/月/日剩余环、点阵倒数日、纪念日横卡 |
| 设备状态 | 分段电池、环形电量、系统磁盘仪表 |
| AI 额度 | Codex、Claude、双账户横卡、额度与本机 Token 图表 |
| 音乐 | 黑胶方形、黑胶横向、封面海报、浮层、复古桌面、磁带、迷你播放条 |

倒数日的“数据源”中可设置名称和目标日期。设备状态读取 Windows 电池和系统磁盘信息；无电池或读取失败时保留未知状态。天气沿用原有城市与 Open-Meteo 数据。

播放器沿用系统媒体会话和真实控制能力。复古与海报样式的进度条仅在媒体提供时长和跳转能力时启用；其他情况显示未知时间并禁用操作。

## AI 额度来源

“数据源 → 用量 JSON 文件”留空时，Codex 从本机 `CODEX_HOME/sessions`（未设置时使用用户目录中的 `.codex/sessions`）读取真实 `rate_limits` 记录。显示的是**剩余**百分比；已经到达重置时间而没有新记录时显示未知，不自行填成 100%。卡片保留来源记录的更新时间。

Token 图表展示已读取的本机记录，含缓存输入，不是账户账单或全部设备用量。后台读取最近 7 天中最近修改的 16 个日志文件，每个文件最多读取尾部 4 MB；截断位置之前的累计值不算入当天数据。额度与图表约每分钟更新一次，隐藏组件沿用现有暂停刷新逻辑。

Claude 暂无自动账户接口，按用户选择提供 JSON 文件入口。没有数据时显示“未接入”，不使用示例百分比代替真实额度。填写文件路径后，该模板使用文件中的数据；文件可同时提供 Codex 和 Claude，也可只提供其中一个。

文件最大 2 MB，格式如下；将 `null` 替换为你实际获得的数值与 ISO 8601 时间。`remainingPercent` 范围为 0–100。

```json
{
  "codex": {
    "updatedAt": null,
    "fiveHour": { "remainingPercent": null, "resetsAt": null },
    "week": { "remainingPercent": null, "resetsAt": null },
    "dailyTokens": []
  },
  "claude": {
    "updatedAt": null,
    "fiveHour": { "remainingPercent": null, "resetsAt": null },
    "week": { "remainingPercent": null, "resetsAt": null },
    "dailyTokens": []
  }
}
```

`dailyTokens` 可包含 `{"date":"YYYY-MM-DD","tokens":非负整数}`。路径按模板保存，也可在桌面组件设置中单独填写。文件内容只作为数据解析，不执行日志或文件中的文本，不读取账户凭据。
