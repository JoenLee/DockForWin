# 小组件多版式与独立配色

本轮承接用户新增要求：圆角再大一点、卡片支持自配色，以及提供更多参考图中的不同版式。此文优先于之前完整超椭圆和较小圆角版本。

## 当前效果

- 连续圆角半径为 `min(20 DIP, 短边×19%)`：现有小卡约 15.96 DIP，大卡 20 DIP。保持直边、共用裁剪/边框/阴影轮廓；共享 DockSurface 源码未修改。
- 天气 6 款：一眼天气、今日天气、天气速览、五日预报、温度海报、预报面板。
- 日历 7 款：今天、接下来、月历、月历与日程、数字月历、日历与天气、时间与日期。数字月历含大月份水印；时间与日期显示真实本地 HH:mm。
- 仍在同一纵向页面内，每个分类独立有界轮播；鼠标在轮播内滚轮不带动页面，首尾也不循环。相邻卡片保持约 22 DIP 的实际边缘间距。

## 自配色

选择卡片后，展开该分类下的“卡片配色 · 卡片名称”。每个注册样式独立保存背景、文字、强调色及渐变设置，修改一张不会改变相邻卡片。

- 可输入 HEX，或打开沿用现有实现方式的 Windows 原生选色器。
- 预设：海湾蓝、暖砂、森林、莓果、暮色紫、极简黑。
- 留空跟随当前样式；可恢复当前卡片默认配色。
- 新版式自带基础配色。背景被自定义而文字未指定时，文字会按底色明暗自动选择；显式指定文字颜色时保留用户选择。
- Light / Dark / Glass 共用一套内容和配置。自配色覆盖对应颜色；Glass 仍使用共享缓存背景与透明色层。
- 更改立即预览，点击窗口底部“保存设置”后持久化。非法输入不会覆盖上次有效值，失焦时恢复有效值并提示。

## 实现范围

修改：Models/WidgetOptions.cs、Views/WidgetHost.cs、WidgetContent.cs、WidgetGalleryPage.cs；新增 WidgetContent.Styles.cs 和 WidgetGalleryPage.Colors.cs。测试更新 WidgetGalleryChecks.cs。

WidgetDefinition 增加轻量版式枚举，旧定义 ID 和顺序保持；新增定义追加到后面。选择范围按注册表计算，CardColors 按定义 ID 深拷贝和 Normalize，沿用 DockSettings 的 Copy/ApplyPreferences 与 SettingsService 保存链路。没有复制轮播或材质业务，没有新增框架。

新时钟和日历复用图库唯一计时器，对齐下一个整分钟；离页停止，屏幕外不刷新。组合天气卡片参与同一天气服务的按需刷新，并显示获取时间。缺失天气显示不可用，不构造示例温度。画刷、渐变和几何缓存均设上限；配色变更更新资源，不重建内容树，不新增 WGC 或 Rendering 订阅。
