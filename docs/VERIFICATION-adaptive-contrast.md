# 衬色与运行指示点自适应 · 2026-11-07

已实现用户要求的背景明暗适配，没有生成或更新安装包。

## 行为

- 现有“淡黑色衬底强度”改为明确的“淡黑色衬底强度上限”；设置保存值仍是原来的 GlassTint，没有修改配置格式或覆盖用户数值。
- 有效黑色衬色在所设上限的 72%～100% 内柔和变化。亮背景接近上限，暗背景减淡；上限设为 0 时始终为 0。
- 从现有玻璃背景帧稀疏取样，避开捕获缓冲边缘；采用约 0.4 秒时间常数平滑亮度，不增加屏幕捕获实例。
- 每个正在运行的应用，依据小圆点附近的局部背景决定亮色或深色。深背景使用近白色，浅背景使用近黑色。中间灰区域使用迟滞避免来回闪烁，明暗色切换采用 240 毫秒柔和过渡；关闭动画/减少动态效果时直接更新颜色。
- 全透明底板仍复用同一实时采样来适配运行点，但玻璃底板继续隐藏。关闭应用窗口后圆点照常隐藏。非液态玻璃模式与高对比度回退继续使用原有指示色。

## 改动范围

新增 `Views/AdaptiveGlassAppearance.cs`，供底板和运行点共用采样、时间平滑及对比决策。修改 `DockSurface.cs` 的衬色参数输入、`DockTile.cs` 的圆点颜色、`DockWindow.cs` 对同一捕获帧的分发，以及设置页说明文字。捕获算法本身不变。

本轮 GlassDesk 的 HLSL、PS 资源、折射/扭曲、Gaussian 磨砂、高光、黑边、底板几何和波浪/换位代码均未修改。原有源码清单中 25 / 30 文件保持 SHA256 一致，其余为上述 4 个界面文件与测试入口；另有新增辅助类和测试文件。

备份：`docs/backups/adaptive-contrast-20261107-5763017c/`。

## 验证

- 核心检查 **55 通过、0 失败**，包括新增的上限/零端点、时间平滑、不同帧率、运行点迟滞和局部采样检查。已有测试工程的两条 nullable 警告未改。
- 隔离实屏检查通过：暗背景自动减淡衬色并显示亮点；亮背景在上限内加深衬色并显示暗点；突变背景时衬色平滑跟随。
- 同一底板跨越左右深浅背景时，两个运行点各自适配局部背景；不仅检查画刷颜色，也确认实屏圆点像素。零衬色、完全透明底板、关闭窗口后圆点消失均通过。
- 原有隔离 GUI 回归通过：实际应用窗口背景与实时变化、先折射再高斯、背景一比一、70 项缩小居中、深色界面、全屏退下及恢复置顶。
- 本次窗口移动时采样约 **38.0 次/秒**，为当前机器和测试场景的观测值，不代表所有场景性能；不把 Rendering 回调次数视作实屏帧率。
