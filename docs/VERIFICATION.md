## 手动试用步骤

1. 双击根目录 Run-Dev.cmd，看到桌面底部的程序坞；再次启动不应出现第二个程序坞。
2. 点击 `+` 选择 exe 或 lnk，或拖入该文件；点击图标启动应用，运行后观察状态点。
3. 打开同应用多个窗口，通过图标或右键菜单切换。部分打包应用和代理启动器有身份限制，见 ARCHITECTURE.md。
4. 拖动固定图标排序，试按 Esc 取消，再退出重启检查顺序。
5. 通过右键添加文件夹，点击打开；点击回收站入口。取消固定不应删除源文件。
6. 调整浅色/深色、大小、间距、位置和隐藏；启用隐藏后离开并靠近对应工作区边缘。
7. 从系统托盘退出，确认程序坞消失；需要时重新运行 Run-Dev.cmd。
