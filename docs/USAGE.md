# 使用说明

## 程序坞

把应用的 EXE、快捷方式、文件或文件夹拖到 Dock，即可固定。管理的快捷方式存入用户数据目录，发行包不会带入作者的快捷方式。点击图标启动或切换窗口；对正在前台显示的窗口再次点击可收起。多窗口应用悬停可查看预览，滚轮可切换窗口。

在设置中调整位置、显示器、尺寸、间距、自动隐藏和材质。底板、玻璃、动画参数共用现有实现。默认不会开启开机自启；需要时在设置里启用并保存。

## 设置与保存

设置中的修改先保留为草稿，部分修改可在桌面实时预览。点击“保存设置”才提交。取消恢复已保存内容。关闭设置窗口可能将它隐藏到托盘，草稿仍在当前进程中；重启前请先保存需要保留的草稿。

## 控制中心

默认快捷键是 `Ctrl+Win+A`，可在设置中修改。控制中心提供网络、蓝牙、音量、亮度、媒体等入口。拖动、尺寸切换及分组使用已有布局管理。系统或硬件不支持的操作会反馈不可用，或打开 Windows 原生工具。

开启接管右侧快捷设置入口后，可按住 Ctrl 点击任务栏对应区域来打开 Windows 原生面板。

## 小组件

在设置 → 小组件中切换分类，选择样式、支持的网格尺寸、数据源和外观，然后添加到桌面。拖动组件的非交互区域调整位置；右键打开组件菜单。布局避让已有组件和桌面图标。

- **时钟：**读取 Windows 当前系统时间。普通款默认本机时区；城市和世界款使用各自配置的时区。指针会重新对齐系统时间，关闭动画也不会停止走时。更换电脑时默认时区由新电脑生成，已有明确选择的时区保留。
- **天气：**选择城市或授权位置。实况、预报、日出和日落来自 Open-Meteo；读取失败会保留可用旧数据并反馈错误。
- **音乐：**先在支持 Windows 系统媒体接口的软件中播放。播放、暂停和切歌由真实媒体接口完成；只有播放器支持时才能拖动进度、随机或循环。iPod 圆盘支持鼠标滚轮调整系统音量，MENU 查看本应用最近播放。唱机在暂停时将唱针移回支架，恢复播放时移回唱片。
- **账号来源：**To Do、OneNote 等来源需要主动连接 Microsoft 账号。未连接或授权失败时不假装已有数据。
- **闹钟：**Windows 没有通用的系统闹钟读取接口，组件提供打开 Windows 时钟的入口。

## 数据备份与迁移

正常安装的数据目录是 `%LOCALAPPDATA%\DockForWindows`。退出程序后复制该目录即可备份；在另一台电脑恢复时，机器相关的固定应用路径需要重新选择。安装包不包含任何人的数据目录。

升级沿用现有配置；卸载保留配置。如果确实需要重新开始，请先备份，然后退出程序，自行移走该用户数据目录，再启动程序。

高级启动参数：

```text
DockForWindows.exe --settings
DockForWindows.exe --control-center
DockForWindows.exe --data-directory "自选的数据目录"
DockForWindows.exe --shutdown
```

`--data-directory` 用于明确选择独立配置；程序不会从某个固定盘符自动导入作者的开发配置。再次启动默认会唤出已运行的同一实例。

## 发布校验

安装包旁提供 `SHA256SUMS.txt`。在 PowerShell 中执行：

```powershell
Get-FileHash .\DockForWin-Setup-1.0.0-x64.exe -Algorithm SHA256
```

将输出与校验文件比较。首发版本主要验证于 Windows 11 x64；不同显卡、多屏 DPI、硬件控制和播放器能力仍会受到具体环境影响。
