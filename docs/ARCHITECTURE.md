# DockForWindows 0.4 架构

WPF 负责程序坞与设置窗口，Windows Forms 负责托盘、系统选色器和屏幕信息。Models 保存偏好与固定项；Services 封装 Shell、窗口跟踪、主题计算和持久化；DockViewModel 管理项目；Views 处理呈现与交互。没有网页容器或第三方 UI 包。

## 曲线与布局

DockSurface 用三次超椭圆族代替普通圆角近似。圆润度归一为 p∈[0,1]，实际角部范围 r=p×min(width,height)/2；角部指数 n=3−p⁸。大部分范围保留三次超椭圆的轮廓，接近 100% 时连续向 n=2 过渡；只有 p=1 才采用半圆端帽胶囊。

角部满足归一化的 |u|ⁿ+|v|ⁿ=1，用分段三次 Hermite/Bézier 近似绘制。中段保持直边，不把整个长条拉成椭圆。圆润度可按 0.1% 调整。JSON 字段仍沿用 CornerRadius 名称，但 0.4 的 UI 含义为圆润度百分比。

图标中心线固定；放大围绕该线进行。底板高度只围绕图标本体计算，倒影和弹跳使用独立留白。底板与图标在底部、左右停靠时分别使用对应的中心轴对齐。

## 动画与透明输入

DockStrip 只在配置或项目变化时测量和排列。动画帧仅修改缓存的 ScaleTransform 和 TranslateTransform，不逐帧触发布局测量。插值按实际帧间隔计算，收敛后取消 Rendering 订阅。

Windows 分层透明窗口可能对完全透明像素进行穿透命中，图标移动又可能触发合成鼠标事件。交互层使用视觉上不可辨的 1/255 alpha 输入面，实际可见底板在 100% 透明时仍完全移除；同时忽略坐标未变的合成移动，并仅在真实离开交互区域时复位。这样避免“放大—失去命中—缩小—再次命中”的反馈。

DockTile 没有悬停或选中填充。图标、运行点和倒影在缓存图层中绘制，倒影先对完整图像翻转，再在独立视口内裁切、淡出，可叠加模糊。启动和切换可使用可调高度、时长的有限弹跳。

## 设置与主题事务

设置采用 iOS 风格浅深色卡片、圆角选择器、胶囊按钮、蓝色滑条与白色滑块、绿色开关，保留桌面侧栏分类。界面资源由 IosStyles 提供，原生选色器仍由 Windows 提供，不使用 Apple 专有图标。

设置使用副本预览，正式设置保持独立。保存先写入候选配置，成功后应用；失败则保留原值。退出、取消或关窗回滚预览。提交偏好时合并当前固定项及最近记录，避免设置打开期间新增的项目丢失。

ThemeService 计算底座、边框、运行点、圆润度及阴影。自定义不透明度为零时，底座、边框和阴影同时关闭。关闭系统透明或远程桌面时普通半透明主题可降为纯色；高对比度沿用系统颜色。

## 项目与系统 API

显示顺序为固定非回收站项目、未固定运行/最近项目、回收站。分隔线独立于主题边框透明度。最近项只记录本程序观察到的窗口，不查询其他软件的私有历史。

Shell 启动原始目标，包括 lnk 参数和普通文档关联。图标异步在 STA 线程提取并冻结缓存。EnumWindows、进程路径和 DWM cloaked 状态用于分组；WinEventHook 监听窗口和前台事件，180 ms 合并，5 秒刷新兜底。SetForegroundWindow 遵循系统限制，关闭仅发送 WM_CLOSE。

配置写临时文件后原子替换、保留备份；日志限长。命名 Mutex 和事件提供单实例与打开设置的入口；退出释放钩子、托盘和事件订阅。

## 剩余平台边界

UWP、ApplicationFrameHost、打包代理、管理员权限和虚拟桌面仍可能限制身份或激活；无窗口后台进程不等于运行点。没有承诺全应用的跨进程动画。真实双屏、混合 DPI、热插拔、Windows 10、远程桌面和 Explorer 重启仍需专项验收。未加入真实背景模糊、开机自启、更新或最终发布。
