# 控制中心入口滑出调整 · 2026-11-10

用户希望弹出更接近现有卡片展开的顺滑感，减少逐段闪亮和阻滞。仅修改控制中心入口，不修改卡片详情、收起、布局、图标、背景捕获或材质。

## 问题与最小修改

原入口同时叠加窗口淡入和每张卡片淡入，两层缩放初始值相乘为 0.846，逐行延迟最高 140ms。代码上会放大逐段出现及缩放感，是闪亮和起步发涩的疑似原因，并非通过 GPU 跟踪认定的性能瓶颈。

- `ControlCenterWindow.AnimateOpen`：保留窗口 24DIP、卡片 18DIP 位移及方向；只保留整体淡入，淡入约 192ms。
- 初始窗口缩放改为 .985、卡片 .99；逐行延迟从 25ms/最高140ms 改为 10ms/最高60ms。
- 位移和缩放使用现有详情页 .82 阻尼，通过速度补偿保留原衰减节奏。分析曲线收敛时长从 423.07ms 变为 406.71ms（约 -3.87%）；没有新增曲线系统。
- `ControlMotion.To` 追加可选 damping 参数，默认仍为 .90；保留中途切换的速度衔接及原弹簧求解。
