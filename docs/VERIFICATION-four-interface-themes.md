# 四套统一布局界面主题与逻辑修正 · 2026-11-07

已接入四套应用界面配色：柔彩、紫曜、极简黑白、暖橙。参考第二张侧边导航，四套共用完全相同的三栏、行高、控件模板、字体和尺寸；切换只改变配色，保留窗口大小、位置、最大化状态和当前目录。

入口：预览区下方四个主题按钮；或“系统与启动 → 界面主题”。浅色、深色、跟随系统仍独立保留。界面主题保存至 `InterfaceStyle`，与 Dock 材质、图标布局和玻璃参数独立；点击保存才提交，取消恢复。

## 修正用户指出的问题

- 删除设置窗口的背景采样/高斯模糊组件，恢复完全不透明、清晰底色。右侧玻璃材质预览和桌面 Dock 的磨砂继续按原设置工作。
- 导航使用同一套矢量线条图标，移除字符符号拼接；共同使用固定行高和选中标记。
- 滑块拇指为真实两端半圆的 34×22 DIP 胶囊，阴影位于不裁剪的外层；轨道、开关、按钮均使用统一模板。各主题尺寸没有差异。
- 普通浅色、深色、跟随系统不再被误判为不能自定义。圆角、边框及阴影直接采用用户参数；关闭阴影真实移除桌面效果。底色字段与实际普通主题颜色一致；修改底色进入自定义配色。
- 非玻璃主题仅关闭玻璃专属调节。边框/自定义运行点在非玻璃模式可用；玻璃仍使用独立高光和自动适配的运行点。倒影继续遵守第 15 项的“完全无底板才可用”，动画、最近应用和阴影仍分别遵循自己的开关。
