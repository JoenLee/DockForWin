# 控制中心设计器

双击 index.html 即可离线调整。四种规格共用四列网格：1×1 圆形、2×1 胶囊、2×2 正方形、4×1 矩形。切换编辑模式后，拖动卡片换位，拖右下角切换规格，其余卡片自动让位。

整体缩放作用于整个面板；组件缩放一起调整卡片、图标、文字与卡片间距。调节组件大小不会改变形状的长宽比。亮度、音量保持横向滑条。二级页也可以在设计器中预览。

预览满意后导出 JSON。在新版桌面程序的「设置 → 控制中心 → 导入网页设计参数」中选中这个 JSON，再点「保存设置」。下次打开控制中心即可看到效果。导入仅更新布局、尺寸与圆角，不覆盖玻璃材质、快捷键或 Dock 的固定应用。网页用于调整布局；真实背景折射和系统控制由 Windows 原生控制中心提供。
