# DockForWindows · 开发预览 0.6.0

原生 Windows 桌面程序坞。工程、SDK、配置、日志和测试均位于 `D:\DockForWindows`。本轮仍不打包最终 exe。

## 启动与设置

- 双击 `D:\DockForWindows\Run-Dev.cmd` 启动。
- 双击 `D:\DockForWindows\Open-Settings.cmd` 打开设置；也可右键程序坞或使用系统托盘菜单。
- 已运行时再次启动会显示原实例。托盘或右键菜单中有退出入口。

## 设置分类

| 左侧分类 | 可调整内容 |
| --- | --- |
| 外观与主题 | 设置窗口独立的跟随系统、浅色、深色；底板主题和液态玻璃折射强度；透明度、圆润度、颜色与阴影 |
| 图标与倒影 | 图标大小、间距；倒影开关、强度、长度、间距和模糊 |
| 动画与交互 | 波浪放大倍率、上浮高度、动画开关、弹跳高度和弹跳时长 |
| 应用与文件 | 添加应用、任意文件或目录；运行应用与最近应用显示、最近项数量 |
| 位置与行为 | 底部、左侧、右侧、显示器、底边距离、全屏退下及普通窗口自动隐藏 |

调整会即时预览。点击“保存设置”才提交偏好；取消、直接关窗或在预览中退出程序，均不保存临时主题。最近应用历史可能独立更新，不属于主题预览。

圆润度为 **0～100%，步长 0.1%**。以三次超椭圆为基础连续过渡，只在 100% 到达两个半圆端帽。它不会把整个长条变成椭圆。

透明度为 **0～100%**。100% 时移除底板、底板边框和阴影，图标、运行点、分隔线及倒影仍按各自设置显示。

弹跳默认比最初版本更高、更慢。弹跳高度 8～64 px，时长 350～1800 ms；时长越大，速度越慢。倒影强度为 0～100%，长度为图标高度的 5～100%。

## 固定、分区与文件

- 固定项目在左侧；运行中和最近使用的未固定应用在分隔线右侧；回收站始终最右。右侧没有加号按钮。
- 直接拖入 exe、快捷方式、普通文件、文档或文件夹即可固定；也可通过右键或设置中的添加入口选择。
- 可以从安装目录或开始菜单添加，不依赖桌面。快捷方式会复制到 `data/shortcuts`，并保存真实目标、参数及工作目录；删除原桌面快捷方式后仍可启动。程序本体、文档及文件夹仍位于原位置。
- 原固定项丢失桌面快捷方式时，自动按已知程序路径或应用 ID 修复；图标失败不会缓存占位图，右键底板可重新加载图标。
- 普通文档使用 Windows 默认关联程序打开；不支持的关联由系统提示。添加不会修改源文件，取消固定也不删除源文件。
- 点击应用会启动它或切换到已有窗口，同应用多窗口可循环切换，也可从右键菜单选择。运行点基于可识别的顶层窗口。
- 拖动固定项目时两个图标实时平滑对调，松开保存；Esc 动画复原。回收站不参与排序。
- “请求关闭这些窗口”发送正常关闭请求，保留应用自身的保存提示，不强制结束进程。
- 图标较多时整排等比缩小，减少后恢复到设定尺寸。图标与底板以显示器中心对齐；悬停波浪只向上，底板在原高度伸长。
- 普通窗口下可保持置顶；前台应用最大化或全屏时约 440ms 柔和退下并下沉，恢复普通窗口后约 540ms 呼出。可选在普通窗口下也自动隐藏。屏幕边缘可临时唤出。

## 通透液态玻璃

“外观与主题”选择“液态玻璃”。折射强度、边缘扭曲度、高斯磨砂、透明度、上下高光强度与宽度、左右暗边、淡黑色衬底分别调节。中央保持背景原比例；仅四边与四角连续回弯。磨砂在折射后叠加高斯模糊，不使用颗粒噪声。默认有约 6% 的透明淡黑色衬底。

Windows Graphics Capture 保留后方窗口的最新 GPU 帧，只读回程序坞附近区域；移动窗口时同步更新位置与内容。折射、模糊、高光分别在 GPU 渲染。取样忙时跳过，不堆积任务；实际帧率取决于窗口、尺寸与硬件，本机移动测试窗口约 40 次/秒。未设置截图排除。受保护或不支持捕获的窗口可能回退；它是 Windows 上实现的玻璃材质。

上下高光从边缘向内窄幅渐隐，左右暗边有轻微下沿反光；外层投影不受玻璃内容的裁剪影响。投影可用“启用底座阴影”“阴影强度”“阴影柔和度”调整。

## 工程与开发

```text
src/DockForWindows/    C#、WPF 工程
tests/                功能检查、GUI 测试记录和截图
tools/                本地 SDK、Build.ps1、Run.ps1、Test.ps1 与桌面检查脚本
data/                 settings.json、备份与 dock.log
docs/                 架构、验证报告、历史备份与原始需求
```

```powershell
Set-Location D:\DockForWindows
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\Build.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\Test.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\Run.ps1
```

工程内 .NET SDK 为 10.0.403，使用微软 Windows SDK .NET 引用 10.0.26100.57。目标为 net10.0-windows10.0.26100.0，最低 API 版本为 Windows 10 2004；没有第三方运行库。缓存留在工程中，不修改系统 PATH。输出目录继续为 `bin/Debug/net10.0-windows`，开发输出是 DLL，由 `tools/dotnet/dotnet.exe` 启动；没有最终 exe 发布或打包。`Compile-Shaders.ps1` 用系统 D3D 编译器生成工程内 GPU 着色器。

提供的启动脚本将 `DOCKFORWINDOWS_DATA` 指向工程 data 目录；不经脚本手动启动 DLL 且未设置该变量时，才回退到 LocalAppData。

GUI 测试脚本会短暂移动鼠标、打开设置和空白测试窗口，结束后恢复原有配置和鼠标位置，适合在不同时操作程序坞时运行。

## 当前边界

完整 UWP 身份、部分代理启动器、受保护的窗口采样和权限隔离窗口仍有限制。最近应用依据已观察到的窗口及前台切换记录，不扫描所有系统使用历史。Windows 10、真实双屏和混合 DPI 仍需专项验收。

本轮未加入开机自启、更新、窗口缩略图、跨进程 Genie 特效或最终 exe 打包。最新证据见 `tests/latest-core-results.txt`、`tests/glass-layout-results.txt` 与 `docs/VERIFICATION-latest.md`；旧版验证记录保留作历史资料。
